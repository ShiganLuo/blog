拾感日记 · 博客系统架构

Spring Boot 3.4 分层后端 · Vue3 双前端 · MySQL/Redis/MinIO · nginx-proxy 统一入口 · 阿里云 ECS Docker Compose 部署

前端层（blog-vue3）

  • • 前台/后台两个独立 Vue3 SPA，构建产物打成 Nginx 镜像
  • • 前台 history 路由：/book /article 直链可刷新（非 hash）
  • • 目录统一交互：右边界 hover 把手（跟指尖）→ 右侧 420px 弹层，正文恒全宽
  • • TocTree：onGetCatalog 构建层级树，父节点折叠，>40 标题默认全折，滚动高亮
  • • 后台菜单 = 前端静态 asyncRoutes，书架编辑页 isHide 只能从列表按钮进
  • • 静态策略：index.html no-cache + 哈希资源 immutable，发版即生效

后端分层与书架设计

  • • 安全: JWT 双令牌 1h/14d，/api/admin/** 认证，/api/front/** 白名单
  • • 登录: kaptcha 图形码 + 滑块，Redis 存 CAPTCHA:IMG:<uuid> 5 分钟
  • • Controller admin 15 + front 14 · Service 19 · Mapper 15 · entity 20
  • • 书架: book/book_article 多对多，FK CASCADE，编排加/移/排/改名/上架
  • • ZIP 导出: 目录 + 逐章 Markdown，MinIO 回源下载图片去重改写引用
  • • 图片只存相对路径，@MinioFile 读时拼 public-base-url

部署拓扑

  • • nginx-proxy 统一 HTTPS：blog.→web · back.→admin · /api → backend:8080
  • • 生产: 阿里云 ECS docker-compose-remote.yml，blog_net 与 bioplatform 共用
  • • 共用代理重建后必须 nginx -s reload（proxy_pass 域名加载时解析成 IP）
  • • 本地: docker-compose.yml 自带 MySQL/Redis/MinIO（3308/6380/9007）
  • • 发布: 本地 build → docker save tar → ssh 管道 → load → force-recreate
  • • 禁远程 build · scp 被 shell 环境拦截改用管道传输
