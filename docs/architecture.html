拾感日记 · 博客系统架构

Spring Boot 3.4 + Vue3 + MySQL/Redis/MinIO — 单机 Docker Compose 部署

前端层

  • • 前台 / 后台两个独立 Vue3 SPA，构建产物打成 Nginx 镜像
  • • Nginx 双层反代，两层都透传 Authorization 头，JWT 才能穿透
  • • 前台首屏拉 getFrontInfo 初始化站点信息（favicon 等）
  • • 后台菜单 = 前端静态 asyncRoutes，按权限过滤

后端与安全

  • • 单体 Spring Boot：controller / service / mapper 三层 + DTO
  • • JWT 双令牌：accessToken 1h + refreshToken 14d，Redis 存刷新票
  • • /api/admin/** 白名单排除，防止全后台跳过鉴权
  • • 图片库内只存相对路径，@MinioFile 读时拼 public-base-url

数据与存储

  • • MySQL 主库（文章/评论/用户/相册），首次启动 blog.sql 建表
  • • Redis：浏览量计数、缓存、refresh token 黑名单
  • • MinIO my-bucket 匿名公开读，卷持久化到 ./database
  • • 部署：本地 build → tar → scp → 远程 docker-compose 重建
