# 前台书架页专属模板设计（审阅稿 v1）

## 1. 背景与目标

现状：`views/book/book.vue` 是从相册页 `photo-album.vue` 复制改造的——`el-row` 四列网格 + 横版图片瓦片 + 左上角半透明蒙层放标题/章节数。实测线上 `/book`（3 本书）渲染出来就是一组“照片墙”，和“书”没有任何视觉关联，更谈不上“书架”主题。

目标：重写书架页模板，让它**一眼看上去是个书架**：书立在隔板上、竖版书封、抽书动效；不再复用相册布局。接口、路由、阅读页全部不动。

## 2. 现状事实（线上实测）

- 书 3 本：RNAseq(2章)、硬件(2章)、Linux系统笔记(4章)，一行 4 列留一个空位。
- 封面比例混杂：两张 554×554 方图、一张 299×168 横图，被硬裁成 ~201×196 的横方格——横图当书封展示先天不成立。
- `subtitle` / `description` 基本为空，蒙层实际只显示书名 + N 章。
- 无封面的书目前是灰色块 + 图标占位，不像“一本没有封皮的书”。

## 3. 方案选项

### 方案 A：实体书架（书立在木质隔板上）——推荐

```
   ┌─────┐ ┌─────┐ ┌─────┐
   │ 封面 │ │ 封面 │ │ ░░░ │   竖版 2:3 书封，高度随书微差（按 id 取模 3 档）
   │     │ │     │ │占位 │   底部渐变遮罩：书名 + N 章徽章
   │     │ │     │ │     │   无封面 → CSS 生成布纹封面 + 竖排书名
   └─────┘ └─────┘ └─────┘
 ▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬   木质隔板（低饱和棕渐变 + 顶边高光 + 落影）
   书名·2章                      hover：书沿隔板向上抽出 translateY(-14px) + 投影加深
```

- 所有封面统一裁成 2:3 竖版（`object-fit: cover`），方形/横图都能成立。
- 书多了自动换行，每行各自带一块隔板，天然是“一层层书架”。
- 移动端 ≤768px 两列小书架；骨架屏改成竖版书形。

### 方案 B：立体书 + 借书卡

- 纯 CSS 3D：左侧书脊条（竖排书名）+ 封面 + 右侧书口（几条白线模拟纸页），hover `rotateY` 微微翻开。
- 书下方挂一张“图书馆借书卡”信息条（书名/副标题/N 章/开始阅读）。
- 拟物感最强、最“书”，但 CSS 复杂度最高，横版封面裁进窄书封后构图风险大。

### 方案 C：图书馆书目列表

- 一书一行：左侧色块书脊 + 书名/副标题 + 章节数 + 阅读按钮。
- 信息密度最高、实现最稳，但视觉上是“目录列表”不是“书架”，主题感最弱。

## 4. 推荐与理由

**推荐 A**：书架主题的辨识度直接由“竖版书 + 隔板 + 抽书动效”三件事构成，全部可由现有字段（coverImage/title/chapterCount）+ 纯 CSS 实现，零接口改动；B 的 3D 细节收益/成本比低，C 偏离“书架”意象。A 也顺带解决封面比例混杂和空封面占位两个现存问题。

## 6. 关键细节

1. 封面统一 2:3 竖版裁剪；`cover-empty` 分支从“灰色图标块”改为 CSS 生成封面（低饱和底色 + 竖排书名 + 纹理渐变）。
2. 隔板配色用低饱和棕（`#8b6b4a` 系渐变 + 顶部 1px 高光 + `box-shadow` 落影），贴合站点浅色主题；文字用 `var(--global-white)`。
3. 书高按 `id % 3` 取三档（如 15rem / 16rem / 17rem），避免等高像栅格；同层隔板对齐。
4. hover 抽书：`transform: translateY(-14px)` + `box-shadow` 加深 + 过渡 0.25s；点击仍是整卡进 `/book/read?bookId=`。
5. 章节数徽章做成书签飘带样式（顶部小三角缺口），贴书架语义。
6. 骨架屏：`SkeletonItem` 换成 4 个竖版书形占位，保持加载节奏不变。
